# 🏎 F1 Miami Grand Prix Power BI Analytics

An interactive Power BI dashboard analyzing Formula 1 Miami Grand Prix race data.

## 📊 Dashboard Pages

### 🏠 Home
Project introduction and dashboard navigation.

### 🏁 Race Overview
Provides an overview of the race including:
- Driver finishing positions
- Race pace by lap
- Tyre strategy
- Race statistics

### 👤 Driver Performance
Allows users to analyze individual driver performance:
- Final position
- Fastest lap
- Average lap time
- Top speed
- Lap time analysis
- Sector performance
- Position distribution
- Speed analysis

### 🏎 Team Performance
Analyzes constructor/team performance:
- Team race pace
- Team finishing performance
- Driver finishing results
- Team speed distribution

## 🛠 Tools & Technologies

- Power BI
- DAX
- Power Query
- Python
- FastF1
- PostgreSQL
- SQL

## 📂 Dataset

The project uses Formula 1 race data obtained through FastF1 and processed for Power BI analysis.
